# Qelvoriflix Key Admin
Aplicativo Android nativo para administrar licenças por HTTPS.
Endereço do servidor, usuário e senha são inseridos no aplicativo.
Não insira senhas no código-fonte. O backend FastAPI está no pacote ZIP Qelvoriflix Key System.
O APK não substitui o Qelvoriflix Pro; o app cliente exige validação periódica no seu código principal.
